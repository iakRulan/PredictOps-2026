## 二、 方向性指标对齐（官方表述为「建议目标值」，非硬性门槛）

| 指标维度 | 建议目标值 | 实测达成 | 数据口径 | 达成 |
| :--- | :--- | :--- | :--- | :---: |
| **故障分类准确率** | ≥ 85% | **89.9%**（按样本留一 LOSO） | **真实公开数据集**：NASA CWRU 原始 `.mat` 驱动端加速度，21 只可比样本 / 168 段真实窗口，宏平均 F1 = 0.889 | ✅ |
| **特征频率识别偏差** | 官方未设（自定 ≤2%） | **−0.81% ~ +0.40%**（绝对值 ≤0.81%） | 真实波形包络解调实测值 对比 6205-2RS 理论系数导出值（12/21 只有可检出分量） | ✅ |
| **故障元素判定一致率** | 官方未设 | **16 / 21** | 官方目录为真值；未判出的 5 只集中在滚珠故障（B007 信噪比低于门限），如实保留 | ✅ |
| **预警提前时间** | ≥ 24 小时 | **36.0 小时** | 仿真运行态注入实测（区间 24~72h，仿真集均值 41.2h） | ✅ |
| **误报率** | ≤ 10% | **2.8%** | 仿真扩充集预警级统计（设定口径，非真实数据测量） | ✅ |
| **健康指数量化** | 0-100分 + 评分依据 | **五维加权透明公式** | 振动峭度 / 包络能量 / 温升偏离 / 电流波动 / 疲劳累积，实时子分数可复算 | ✅ |
| **知识库问答** | 自然语言检索 | **智能对话工作台** | 语义检索故障原因、排查步骤与国标 | ✅ |
| **样本覆盖（建议）** | ≥3类设备、≥5种故障、每类≥1000条 | **3 类 / 5 种 / 1,200 条** | 18,000 条为**参数化仿真扩充集**；真实公开样本另计（21 只 .mat / 168 段窗口，3.7 MB） | ✅ |

> **官方措辞**：赛题「数据说明」原文为「参赛者**自行准备数据**，**建议**以下来源」，指标表表头为「方向性指标 · **建议目标值**」——
> 接入真实公开数据不是强制项，本项目做它是为了让准确率有可复算的测量出处（逐字原文见 `docs/TRACK04_COMPLIANCE_AUDIT.md` 第 0 节）。
>
> **口径说明**：本系统区分两条数据路径并在界面分列展示——**真实路径**为构建期从 CWRU 官网下载的 `.mat`
> 原始波形（记录文件名、字节数与 SHA-256 供溯源），由页面内 JS 现场做带通 + Hilbert 包络解调；
> **仿真路径**为 `SimEngine` 参数化生成的设备时序，用于演示预警、RUL 与工单闭环。
> 预警提前时间与误报率需要轴承全寿命失效记录才能真实测量，公开样本尚不覆盖，故明确标注为仿真口径，
> 不与真实测量混列。按窗口留一（LOO）93.5% 仅作对照并在界面上标明偏乐观——同一只 .mat 切出的窗口高度相关。
> 复现：`./tools/fetch-cwru.sh` → `node tools/cwru-extract.js <mat目录> assets/data` → `node tools/cwru-cv.js`。
