## 📖 项目简介

在现代工业制造现场，核心动力与旋转设备（数控机床、螺杆空压机、工业离心泵）非计划停机损失巨大。传统的“事后维修”与“定期巡检”模式缺乏对多源物理量的实时关联分析与早期微弱故障识别。

**「智维 · PredictOps」** 依托卡奥斯 COSMO Code AI 智能开发平台从零构建，打造集“多源感知、算法推理、工单决策、专家知识”于一体的工业设备智能管理与预测性维护系统。

## 🏛 系统四层闭环架构

```
┌────────────────────────────────────────────────────────┐
│  4. 知识层：专家诊断知识库 + 自然语言对话交互与经验检索  │
├────────────────────────────────────────────────────────┤
│  3. 决策层：智能工单自动生成 + 备件库存联动 + 闭环流转  │
├────────────────────────────────────────────────────────┤
│  2. 推理层：提前24-72h早期预警 + 量化健康评分 + RUL推演 │
├────────────────────────────────────────────────────────┤
│  1. 感知层：多源时序采集（振动/温度/电流）+ 健康基线监控│
└────────────────────────────────────────────────────────┘
```

### 1. 感知层 · 时序采集与基线监控
- **多设备支持**：数控加工中心（VMC-850）、螺杆空压机（GA-75VSD）、单级离心泵（IH100-65-200）。
- **多源物理参数融合**：振动加速度（m/s²）、振动位移（µm）、轴承/排气温度（℃）、工作电流（A）。
- **动态基线与特征频谱**：实时计算动态健康基线与 0~1000Hz 物理频谱，标注 1X、2X 转频及 BPFI/BPFO 故障特征频率，配备交互式告警测振游标。
- **NASA CWRU 基准验证**：集成 7 组标定数据集样本，对比理论计算特征频率与算法包络解调识别值（偏差 < 2%）。

### 2. 推理层 · 早期预警与寿命推演
- **五维量化健康评估模型**：
  $$H = \sum_{i=1}^{5} w_i \times S_i$$
  * 振动时域峭度指标（Kurtosis，权重 30%）
  * 频域包络能量占比（权重 25%）
  * 轴承热平衡温升偏离度（权重 20%）
  * 负荷电流波动谐波（权重 15%）
  * 历史劣化累积疲劳因子（权重 10%）
- **RUL 剩余寿命预测**：结合加速劣化幂律模型与置信区间（Confidence Band）推演，清晰标识 60 分停机预警阈值。
- **最近预警事件流时间轴**：实时滚动记录全厂告警事件（设备编号、故障类型、提前量、模型置信度）。

### 3. 决策层 · 智能工单与备件流转
- **告警自动衍生工单**：异常工况秒级自动触发结构化检修工单，明确故障部件、维修措施 SOP 与安全警示。
- **维修成本与停机预估**：自动测算工单备件费与人工工时费，预估检修停机时长。
- **备件库存智能看板**：实时联动备件在库量、安全库存线、月均消耗速率与预计可用天数。
- **报告导出**：一键生成六章节工业维护分析与工单报表（支持打印与下载）。

### 4. 知识层 · 故障诊断与自然语言问答
- **工业诊断知识库资产化**：系统梳理 8 大类工业设备典型故障排查 SOP 与专家处置经验。
- **自然语言问答引擎**：集成交互式问答窗口与快捷提问胶囊（“轴承温度过高排查SOP”、“离心泵振动超标诊断”、“当前健康最差设备是谁？”）。

## 🚀 快速启动指南

### 环境依赖
* Python 3.7+ 或任意标准静态 HTTP 服务器
* 现代浏览器（Chrome / Edge / Firefox / Safari）

### 本地启动
```bash
# 赋予执行权限并启动服务
chmod +x start.sh
./start.sh
```
服务将在后台以守护进程形式启动，并监听 **8080** 端口。浏览器访问：
[http://localhost:8080/](http://localhost:8080/)
