## 0. 赛题 04 原文（逐字，本仓库核对此前的唯一依据缺口）

> **04 设备智能管理与预测性维护智能应用** · 所属领域：设备运维 · 预测性维护 · 知识沉淀 · 工业场景 · 开放命题
>
> **赛题背景**：制造业设备非计划停机损失巨大，一条产线停机 1 小时损失可达数十万元。当前维护模式以定期点检和事后维修为主，缺乏对振动、温度、电流等关键参数的实时趋势分析与早期异常预警。大量企业设备管理停留在被动维护阶段，维修经验未转化为数字资产，老员工退休导致关键诊断经验流失。
>
> **核心痛点**：故障发现滞后：事后维修模式，故障发生才响应，损失已产生 / 过度维护：定期点检不分轻重，浪费人力且遗漏隐患 / 经验无法传承：老员工退休，关键设备诊断经验随之流失 / 知识未数字化：维修记录纸质化，无法形成可检索的知识库
>
> **任务目标**：构建设备智能管理与预测性维护智能应用，实现以下能力——
> 感知层：采集振动/温度/电流等时序数据，建立设备健康基线；
> 推理层：故障早期预警、劣化趋势预测、剩余寿命（RUL）估算；
> 决策层：自动生成维护建议与工单，关联备件库存；
> 知识层：维修经验沉淀为可检索知识库，支持自然语言问答。
>
> **方向性指标**

| 故障预警准确率 | 基础 | ≥85% |

## I. 真实数据接入轮（2026-10-04）

### I1 为什么要做这一轮

自查发现原实现存在**循环论证**：`dataset.js` 的 `identify()` 用
`measured = theory × (1 + Math.random()×0.018)` 生成「算法识别值」，再判它「偏差 < 2% → 有效识别」；
`eval.js` 的 5×5 混淆矩阵 `CM` 是手写常量，94.6% / 2.8% / 1.02% / 41.2h 全部由它算术派生。
也就是说，被当作 CWRU 集成证据的东西，一次真实测量都没有发生。

### I2 做了什么

| 环节 | 实现 |
| :--- | :--- |
| 数据获取 | 从官网下载 22 只 `.mat`（正常基线 97~100、内圈 105~108/169/209、外圈 130~133/135/144、滚珠 118~122、异型号 3004，约 70 MB） |
| 目录抓取 | `tools/cwru-catalog.js` 解析官方 12k / 48k / 正常基线三个目录页，得 116 条「编号 → 元件/直径/负载/标称转速」映射，并记录 HTML 的 SHA-256 |
| 波形抽取 | `tools/mat5.js` 解析 MAT v5（PCWIN zlib 压缩元素），取驱动端 `X<id>_DE_time`；等时长切窗（标定窗 1.365 s + 8 段评测窗 0.341 s），Int16 PCM 落盘 `assets/data/cwru.bin`（3.66 MiB） |
| 采样率判定 | 由数组长度反推（12k≈12.2 万点 / 48k≈24.4 万点），与目录页标注交叉校验，结果记入产物 |
| 算法 | `assets/dsp.js`：radix-2 FFT → 共振带自动选带 → 频域带通 → Hilbert 解析信号包络 → 包络谱 → 抛物线插值亚 bin 细化。**浏览器与构建期共用同一份文件** |
| 判定 | `|实测−理论| ≤ 2%` **且** `包络SNR ≥ 8`；理论侧转速来自官方目录，实测侧来自波形 |
| 分类 | 留一法 + 最近中心，特征 = 六条包络带能量归一化 + 峭度 + 峰值因子 → 真实混淆矩阵与 P/R/F1 |

工程上踩到并修掉的两个真问题：
1. **60 Hz 工频干扰**：CWRU 驱动端信号含显著 60 Hz 线噪，直接找 1X 会被 40/35 Hz 的假峰带偏；
   改为先对 50/60/100/120/150/180 Hz 邻域陷波再估转频（105.mat 由错的 60.02 Hz → 正确的 30.00 Hz，与目录 1797 rpm 差 0.16%）。
2. **分辨率随采样率稀释**：48k 文件若沿用 16,384 点窗，`df` 从 0.73 Hz 变成 2.93 Hz，
   在 30 Hz 转频上量化误差就超过 2% 判定阈值；改为按**等时长**取窗，12k/48k 的 `df` 统一为 0.73 Hz。

另外发现原样本标签与官方目录不符并已更正：169 是 **12k / 0.014″**（原标 48k / 0.007″）、
3004 是 **内圈 0.028″ @3HP**（原标外圈 0.040″）、122 属 **48k** 表（原标 12k）。
3004 所在 0.028″ 组为另一型号轴承（`.mat` 内变量名为 `X059_DE_time`），6205 系数不适用，已从比对中剔除。

### I3 结果

- 元素判定一致率 **16 / 21**；特征频率实测偏差 **−0.81% ~ +0.40%**（真实测量，非构造）。
- 留一法分类：按样本文件（LOSO）**89.9%（151/168 段真实窗口）**，宏平均 F1 **0.889**，四分类含正常基线类；
  按窗口留一（LOO）93.5% 仅作对照并在界面标注偏乐观——同一只 .mat 的窗口高度相关。
- 滚珠故障 5 只（118~122）逐文件判定全部未检出（峭度 2.72~3.10，贴近健康基线 3.0，冲击能量低于门限）——如实呈现，未做粉饰。
- UI 侧「基准数据集验证」改为**实测 / 模型仿真**双标签：默认实测（真实波形图 + 原始频谱 + 包络谱 + 实测表 + SHA-256 溯源），
  仿真路径显式标注「模型合成频谱，非实测」；评估视图把真实实测与仿真扩充集分列，`metric-foot` 在评估视图放开以显示口径。
