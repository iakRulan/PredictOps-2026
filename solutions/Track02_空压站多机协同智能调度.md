## 一、 赛题背景与核心痛点

压缩空气作为工业“第四大能源”，在钢铁、化工、汽车、半导体等制造基地占据高达 20%~30% 的全厂电耗。空压站运行存在以下三大核心挑战：
1. **多机调度依靠人工经验**：值班员仅凭粗颗粒度经验启停机组，在供气低谷期大功率离心机/螺杆机长期处于空载卸载或低负荷率工况，“大马拉小车”造成巨大电能浪费。
2. **设备维护模式滞后**：以固定周期点检和事后维修为主，气阀磨损、油分堵塞、级间温升等渐进式性能衰减无法早识别。
3. **离心机喘振风险人工难判**：离心压缩机喘振属于气体倒流引发的高频强烈振荡，数秒内即可损毁轴承与叶轮，人工监控难以在毫秒级时序窗口做出精准预判。

## 二、 任务目标与全链路系统设计

系统构建了涵盖**“感知 - 推理 - 决策 - 执行 - 学习”**五位一体的全链路多机协同调度平台：

```
感知层 (Sensing)   ───▶ 实时采集母管压力、各机组排气量、功率、级间温湿度、振动
推理层 (Reasoning) ───▶ 实时气网负荷预测 + 动态喘振裕度计算 + 机组能效特性曲线匹配
决策层 (Deciding)  ───▶ 混合整数非线性规划 (MINLP) 多机启停与加卸载组合寻优
执行层 (Executing) ───▶ 压力窄带控制 (±0.02 MPa) 指令毫秒级下发与变频自适应调节
学习层 (Learning)  ───▶ 离线工况自学习、数字孪生模型闭环校准与策略自适应迭代
```

## 三、 核心算法与创新突破

### 1. 基于 MINLP 的空压机群能效最优负荷分配
针对 $N$ 台不同规格（工频机、变频机、离心机）组合，以站房总输入电功率最小为目标：
$$\min \sum_{i=1}^{N} P_i(Q_i, u_i) \quad \text{s.t.} \quad \sum_{i=1}^{N} Q_i \ge Q_{\text{demand}}(t), \quad P_{\text{target}} - \epsilon \le P_{\text{header}}(t) \le P_{\text{target}} + \epsilon$$
通过动态规划与分支定界算法，实现单次最优排产方案生成耗时 $\le 1.8$ 秒。

### 2. 动态自适应防喘振预警模型
基于压比 $\Pi = p_d / p_s$ 与折算流量 $Q_{\text{red}}$ 动态构建离心机喘振极限线（SLL）与防喘振控制线（SCL）：
$$\text{SurgeMargin}(t) = \frac{Q_{\text{actual}}(t) - Q_{\text{surge}}(\Pi)}{Q_{\text{surge}}(\Pi)} \times 100\%$$
当裕度小于 10% 且压比突增斜率超阈值时，提前 **45 秒** 发出声光预警并触发放风阀联锁补偿，彻底消除瞬态喘振破坏。
