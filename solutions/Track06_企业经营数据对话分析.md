## 一、 赛题背景与核心痛点

企业管理者日常经营分析存在严重的“数据堰塞湖”：
1. **多系统报表繁琐耗时**：订单在 CRM、生产在 MES、财务在 ERP、能耗在 EMS，管理者需要人工跨系统翻找数据、拼凑 Excel。
2. **临时问数严重依赖 IT 排期**：业务部门需要一次交叉分析往往要提交工单等 IT 部门写 SQL，响应周期长达数天，错失经营调整良机。
3. **数据洞察滞后且缺乏解释性**：传统静态图表仅呈现“结果是什么”，无法回答“为什么下滑”和“下一步该怎么做”。

---

## 二、 任务目标与全流程 NL2SQL 架构

系统构建了端到端**企业经营对话分析与自动化智能决策中枢（Enterprise BI Copilot）**：

```
[用户自然语言提问] ──▶ [Schema Linking & 意图理解] ──▶ [NL2SQL 语法生成与安全校验] ──▶ [数据执行与动态图表自适应] ──▶ [多轮下钻与运营日报生成]
```

## 三、 核心技术与算法创新

### 1. 工业级自然语言转 SQL（NL2SQL）生成引擎
- **Schema Linking 与词表映射**：自动加载订单（Orders）、生产工单（WorkOrders）、质量检验（QC）、产线能耗（Energy）四大关系型数据字典；
- **自校验与防注入沙箱**：生成的 SQL 语句经过 AST 语法树校验与只读限制，具备自动纠错机制（语法错误触发反馈重写）；
- **问数解析准确率**：在企业复杂多表联合聚合查询中达到 **93.2%**（官方指标 ≥ 90%）。

### 2. 动态图表智能推荐算法（Chart Matcher）
根据返回结果的数据集特征（维度数、度量类型、时序/离散特性）自动匹配最佳渲染形式：
- 时序增长/趋势指标 $\rightarrow$ 动态平滑面积折线图；
- 结构占比/渠道分析 $\rightarrow$ 环形玫瑰图；
- 多机台/多车间横向对比 $\rightarrow$ 排序条形图；
- 多维绩效/合规评估 $\rightarrow$ 雷达图；
- 转化率/流失分析 $\rightarrow$ 漏斗图。

### 3. 多轮上下文深度对话与指代消解（≥ 8 轮记忆）
支持复杂的跟进式追问，例如：
* *“上个月各车间产量是多少？”* $\rightarrow$ 展示产线柱状图；
* *“其中三车间为什么未达标？”* $\rightarrow$ **自动消解“三车间”**，触发异常归因算法，定位是“2号产线换产停机超限 1.8h”与“物料延期”；
* *“对比一下前三个月的废品率”* $\rightarrow$ 继承筛选条件并横向拉伸时间轴。

### 4. 自动生成多维运营日报（官方加分项）
一键自动萃取当日/当周核心经营指标（订单交付率、总产量、OEE、单位能耗成本、综合良品率），生成图文并茂的 Markdown 运营日报与管理建议。
